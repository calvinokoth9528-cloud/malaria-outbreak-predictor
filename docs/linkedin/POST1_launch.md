Malaria kills 600,000 people every year. 90% of them are in Africa.

I built a machine learning system to predict where outbreaks will happen — before they happen.

Here's what it does:

🔍 Pulls real-time data from 3 global APIs (WHO, World Bank, NASA)
📊 Analyzes 44,000+ data points across 8 Kenyan cities
🤖 Trains a Random Forest model with 6.3% prediction error
📈 Visualizes trends, climate drivers, and regional comparisons

The findings blew my mind:

→ Malaria incidence dropped 68% since 2001 (from 243 to 74 per 1,000)
→ Rainfall is the #1 climate predictor — with a 2-month lag
→ Urbanization is inversely correlated with malaria risk
→ Last year's incidence is the single best predictor of next year's burden

Tech stack:
R Shiny • ggplot2 • scikit-learn • FastAPI • Docker • GitHub Actions

This is the kind of infrastructure KEMRI (Kenya Medical Research Institute) uses for national disease surveillance — and I built an open-source version.
