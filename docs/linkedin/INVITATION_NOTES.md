## 💡 Tips for Sending Invitations

| Do ✅ | Don't ❌ |
|-------|---------|
| Personalize with their name | Send generic "I'd like to connect" |
| Mention something specific about them | Be too salesy or pushy |
| State what you bring to the table | Ask for a job in the first message |
| Keep it under 300 characters | Write a novel |
| Follow up 1 week later if no response | Spam them with multiple messages |
